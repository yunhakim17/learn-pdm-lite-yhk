## EXPLAIN

### 1. 오늘 다룰 데이터

| 용어 | 뜻 |
|---|---|
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 데이터. 한 변수만으로는 놓치는 이상을 여러 변수를 함께 보면 잡아낸다. |
| 진동 (mm/s) | 베어링·회전체 마모, 정렬 불량. 갑작스러운 증가·추세적 상승이 전조. |
| 온도 (℃) | 마찰·과부하·윤활 부족. 서서히 오르는 흐름이 위험 신호. |
| 압력 (bar) | 유압·공압 계통 누출·막힘. 평상 범위 이탈 구간을 표시. |

실습 데이터는 설비 2대 × 25시점(2026-09-15 08:00~16:00, 20분 간격) = 50건이다. **실습용 가상 데이터**다.

| 설비 | 이름 |
|---|---|
| 설비A | 프레스 메인모터 |
| 설비B | 차체 용접로봇 감속기 |

### 2. 왜 단위부터 확인하는가

| 기준 | 바로 분석 | 단위·측정 주기 먼저 확인 |
|---|---|---|
| 단위가 섞였을 때 | 정상값이 이상으로 보이거나 이상이 묻힌다 | 섞인 값을 먼저 찾아 통일한다 |
| 결과 | 이상 판단이 흔들린다 | 같은 기준으로 비교한다 |

원본 강의(Day5 ② 데이터)의 데이터 점검 문장: 단위(℃, mm/s, bar)와 측정 주기를 먼저 확인한다 — 단위가 섞이면 이상 판단이 흔들린다.

### 3. 케이스 — 1분 멈춤이 수천만 원

조립 라인은 한 곳이 멈추면 뒤 공정이 줄줄이 멈춘다. 라인 정지 1분 손실이 수천만 원이다. 그래서 "고장을 미리 아는 것"은 비용이 아니라 생존의 문제다(원본 Day5 덱 · 오늘의 메시지 1).

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. `{SKILL_DIR}`은 Phase A 출력 직전에 이 SKILL.md가 있는 실제 폴더 경로로 바꿔 보여 준다.

```
예지보전 실습 준비를 해 줘.
1. 내 홈 폴더에 pdm-lite-lab 폴더를 만든다.
2. {SKILL_DIR}/assets/lab/Day5_sensor_50_virtual.csv 를 pdm-lite-lab 안에 복사한다. 원본 파일은 고치지 않는다.
3. 복사한 파일의 행 수, 설비 이름, 열 이름과 단위(mm/s · ℃ · bar), 측정 간격을 확인한다.
4. git과 python이 있는지 확인하고, 없으면 설치한다.
5. 위 결과를 pdm-lite-lab/env_check.txt 에 짧게 적는다.
6. 비밀번호나 토큰을 나에게 묻지 않는다.
```

### 확인할 것 (Phase B)

- `~/pdm-lite-lab/Day5_sensor_50_virtual.csv`가 있고 데이터 행이 50개인가
- 설비가 2대(설비A 프레스 메인모터, 설비B 차체 용접로봇 감속기)인가
- `~/pdm-lite-lab/env_check.txt`에 단위(mm/s · ℃ · bar)와 git·python 확인 결과가 적혀 있는가
- 확인이 끝나면 "새 세션 → Local → pdm-lite-lab 폴더 선택"으로 작업 폴더 세션을 열라고 안내한다.

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
pdm-lite-lab 준비에서 무엇이 안 됐는지 env_check.txt와 폴더를 보고 원인을 찾아 고쳐 줘.
```
